# 不做清单

> **这份文件的唯一作用：拦住 AI 给你"看着对、但根本不是你"的建议。**
> 一份只写"要做什么"的档案，会让模型把所有流行做法都往你身上套。写了"不做什么"，它才知道边界在哪。

### 原因分类（只允许这五类）

| 分类 | 含义 |
| --- | --- |
| **人设冲突** | 做了会不像我，或者伤到我立的那条人设 |
| **能力不匹配** | 我没有素材、没有人手、没有条件稳定产出 |
| **平台风险** | 有合规风险、绝对化表述风险、限流风险 |
| **效果差** | 试过，数据或转化撑不起来 |
| **不想做** | 没有理由，就是不愿意。**这条是有效理由，不用解释。** |

## 4. 使用规则（给 AI）

1. 你能提出的方案，如果落进本文件任一条，**必须先说明冲突，再给出替代方案**。
2. 例外栏写"没有例外"的，**不要以任何形式再提**。
3. 例外栏写了条件的，只有条件成立时才可以提。
4. 本文件与 `04-business.md` 的「已验证无效」交叉使用，两者都是硬约束。
