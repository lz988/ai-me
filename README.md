## 给 AI 的读取顺序

1. 先读本文件，再读 `llms.txt`——它是机器索引，比本文件更紧凑。
2. 判清问题落在哪一层，**只读对应文件**，不要全量通读后泛泛作答。
3. 要建议 → `02-thinking.md` + `05-goals.md`，缺一份都会给出"正确的废话"。
4. 要写内容 → `03-voice.md` + 至少一份 `style-samples`。
5. 要选题 → `topics.md` + `rejected-ideas.md`，后者是用来防止跑偏的。

## 写法约定（本仓库唯一的硬规则）

所有文件遵守三条。不遵守的文件等于没写。

1. **写判断，不写形容词。**
   "我要求高"是无效信息；"我宁可少卖，也不留隔夜生鲜"才是可用的信息。
2. **每条抽象结论后面必须跟一个具体例子。** 没有例子的结论，视为未写完。
3. **允许记录错误的判断。** "我当时判断错了，错在把促销当成了拉新"比"我很理性"有用十倍。一个只记录正确判断的档案，模型学到的只会是自恋。

## 隐私边界

以下内容**不写入本仓库**：

- 具体门店名称、精确地址
- 真实流水、毛利、库存与成本数字
- 供应商名称、合同与账期
- 家人、伴侣的姓名与个人信息
- 可直接定位到个人的联系方式、证件信息

这些在私有仓库 `ai-me-private` 中。两者之间靠 `ai-me-private/private/16-公开化提炼.md` 打通：私有内容先提炼成**原则**，原则才允许进入公开层。
